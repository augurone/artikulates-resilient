# Design essays

These essays provide design context and retain their original examples and publication context. The TypeScript essay is a draft. Examples and proposals do not establish current feature support or compatibility.

The TypeScript draft includes proposed JSX/project support and historical helper
paths. Use the [TypeScript guide](../engineering/typescript.md) for admitted
compiler modes and public commands, and the [feature review](../engineering/feature-review.md)
for unsupported direct TS/TSX linting. Earlier essay editions, editorial notes
and book material remain historical rather than additional active specifications.

Use the [Grammar](../reference/grammar.md), [Policy](../reference/policy.md), [Semantics](../reference/semantics.md), and [coding standards](../ai/CODING_STANDARDS.md) for requirements. The [current engineering guides](../engineering/README.md) and [package guide](../../README.md) describe the current implementation and public interfaces.
