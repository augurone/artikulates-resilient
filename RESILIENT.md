# Resilient Project Guidance

The canonical robot instructions for this repository are in
[`AGENTS.md`](AGENTS.md). Read that file before making changes.

Proposed and unimplemented work is isolated in
[`docs/engineering/roadmap.md`](docs/engineering/roadmap.md).

The product dialect is defined by [Grammar](docs/reference/grammar.md),
[Policy](docs/reference/policy.md), and [Semantics](docs/reference/semantics.md).
The [AI guide](docs/ai/CODING_STANDARDS.md) presents the same specification as
an operational checklist.

For a first implementation or review, read
[Writing Resilient from first principles](docs/ai/writing-resilient.md). It
connects the specification, explanatory blogs, and reference code through
boundary decisions and worked examples.
